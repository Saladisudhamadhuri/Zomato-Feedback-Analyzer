🍕 Zomato Feedback Analyzer

A smart food feedback analysis web application built using Streamlit, Python, Pandas, and Plotly.

## 🚀 Features

- Customer Feedback Submission
- Sentiment Analysis
- Food Rating System
- Interactive Dashboard
- Data Visualization
- Product Review Analytics
- Beautiful UI with CSS

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- Regex
- HTML/CSS

## Analytics Included

- Sentiment Distribution
- Average Ratings
- Recent Reviews
- Product-wise Analysis
