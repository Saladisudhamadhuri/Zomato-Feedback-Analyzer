# 🍕 Zomato Feedback Analyzer

A Streamlit-based feedback analysis system for food products.

## 🚀 Features

- Customer review submission
- Sentiment analysis
- Analytics dashboard
- Rating visualization
- CSV database storage
- Interactive UI
- Duplicate review prevention

---

## 🛠 Technologies Used

- Python
- Streamlit
- Pandas
- Plotly

---

## 📊 Functionalities

### Feedback Module
- Submit food reviews
- Give ratings
- Sentiment detection

### Analytics Module
- Sentiment distribution chart
- Average rating graph
- Recent reviews section

---

## ▶️ Run Locally

Clone the project

```bash
git clone YOUR_GITHUB_LINK
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run app

```bash
python -m streamlit run app.py
```
